Редактирование через GitHub

Эта страница — инструкция, а не защищённая панель входа. Доступ к изменению сайта контролируется вашим аккаунтом GitHub. Посетители не смогут редактировать файлы без прав на репозиторий.

  1. Войдите в GitHub под своим аккаунтом и откройте репозиторий bud-stroy.
  2. Откройте файл data.js и нажмите значок карандаша (Edit).
  3. Меняйте price для нужной услуги; чтобы добавить работу, скопируйте соседнюю запись и измените её поля.
  4. Для фотографий измените адреса url в списке photos. Фотографии должны быть предварительно загружены в доступное хранилище.
  5. Нажмите Commit changes. Netlify автоматически обновит сайт после публикации из GitHub.
