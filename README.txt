БУД СТРОЙ v2 — пять отдельных страниц + инструкция по управлению.
Загрузите содержимое этой папки в корень репозитория GitHub bud-stroy (замените index.html, data.js, script.js, style.css; добавьте services.html, prices.html, works.html, contacts.html, admin.html). Netlify подключён к GitHub и должен опубликовать изменения после коммита.
ВАЖНО: admin.html — инструкция, не CMS. Для полноценного редактора с загрузкой фото нужна дополнительная настройка безопасного GitHub OAuth / CMS.
Фото загружаются с Unsplash; убедитесь, что доступность и условия использования соответствуют задачам. Примеры интерьеров не обозначайте как реальные выполненные работы. Цены ориентировочные, требуют проверки.
