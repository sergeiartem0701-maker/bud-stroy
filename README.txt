БУД СТРОЙ — готовый статический сайт для Netlify.

ПУБЛИКАЦИЯ:
1. Распакуйте ZIP-архив.
2. В Netlify откройте Add new project -> Deploy manually (или раздел Deploys).
3. Перетащите ПАПКУ BUD_STROY_site с файлом index.html внутрь в область загрузки.
4. Netlify выдаст адрес сайта.

РЕДАКТИРОВАНИЕ:
- Услуги и цены находятся в data.js. Откройте его текстовым редактором.
- Чтобы добавить фото, скопируйте файл (например, remont1.jpg) в папку images.
  Затем в data.js добавьте в photos запись:
  { title: 'Ремонт ванной', image: 'images/remont1.jpg' }
  Для нескольких фотографий разделяйте записи запятыми.
- После изменений загрузите обновлённую папку на Netlify снова.
- Номер телефона указан в index.html.

ВАЖНО: присланные ранее фотографии не были доступны в этом сеансе, поэтому в архиве
галерея пока без фото. Цены ориентировочные и требуют проверки перед публикацией.
Редактирование осуществляется в файлах сайта, отдельная панель администратора не установлена.
